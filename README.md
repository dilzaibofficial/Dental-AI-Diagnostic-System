## 🌟 Features

* 🧠 **AI Detection (YOLO11m)**
  Detects dental caries, infections, fractures, and impacted teeth from OPG X-rays.

* 📄 **Automated PDF Reports**
  Generates professional dental reports with annotated images.

* 💡 **Smart Medical Advice**
  Automated recommendations based on detected dental conditions.

* 📱 **Responsive UI**
  Works smoothly on mobile, tablet, and desktop devices.

* 📊 **Confidence Threshold Control**
  Adjust detection sensitivity in real-time using sidebar controls.

* ⚖️ **Medical Disclaimer**
  Built-in ethical & legal safety notice (AI ≠ Doctor).

## 🚀 How to Run the Project Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/dilzaibofficial/Dental-AI-Diagnostic-System.git
cd Dental-AI-Diagnostic-System
```

### 2️⃣ Create Conda Environment

```bash
conda create -n dental_ai python=3.10 -y
conda activate dental_ai
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the App

```bash
streamlit run app.py
```
